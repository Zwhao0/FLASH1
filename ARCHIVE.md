# FLASH1 source archive

This repository snapshots the local FLASH1 source tree on 2026-10-17. The `Greyhound/` source was based on upstream commit `d641b3997c17de700e1ef7d37e353418df7e336d`; the archived source includes the ten locally modified source files present at snapshot time. The upstream `.git` directory remains in the local checkout but is not part of this repository.

The root `.ops/` directory contains reproduction and deployment scripts. Local server notes, credential-reading SSH helpers, private experiment reports, generated artifacts, logs, and PDFs were left out. A vendor CI URL had embedded authentication data, which was removed in this archive copy.
